## 四、误差来源判定（按施工单的三分支）


过了门禁的档位误差：St D20 0.02%、D30 0.97%、D40 1.58%；Cd_max D20 1.53%、D30 4.53%、D40 5.43%；Cl 全幅 D20 8.97%、D30 13.81%、D40 14.23%

- St 误差随 D 的趋势：**增大**（0.02% → 1.58%）
- Cd_max 误差随 D 的趋势：**增大**（1.53% → 5.43%）
- Cl 全幅误差随 D 的趋势：**增大**（8.97% → 14.23%）

⚠️ **口径提醒（结构性的，不是这次的结果）**：网格加密档固定 Re 与 U，而 LBM 中 τ = 3ν + 0.5、ν = U·D/Re → **D 组的 τ 随 D 同步增大（0.56 → 0.59 → 0.62），分辨率与黏性离散在这组实验里耦合，单靠本表无法分离两者**。单变量分离需固定 D 与 U、只改 Re（Re→ν→τ）。
