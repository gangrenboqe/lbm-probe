## 🔴 这个项目最重要的产出：一条教训

> **数值模拟里，「看起来收敛的数」和「真实收敛」是两回事。**
> **判据是守恒曲线，不是曲线形状好看。**

起因（2026-10-19，两轮）：

- **第一轮**：跑出「涡街可见、Cl 呈漂亮周期振荡、Cd 从 1.87 平滑降到 1.38」——**曲线形状很好看**，
  我就据此报了 Cd/St。结果复核方盯住**总质量**一看：全网格 Σρ 在前 100 步就跑到 10¹⁵ 量级 → **结果作废**。
- **教训落法**：本目录的求解器与算例脚本现在**每 10 步记录流体总质量 M=Σρ**，
  出 `mass_history.png`（**纵轴取对数**，指数发散一眼可见），
  并内置**发散早停**（出现 NaN/Inf 或质量超初值 10 倍 → 立刻停机）。
  **守恒不过，不报数**——这条现在是硬规矩，优先级高于任何"结果好看"。

## 第二轮的追加教训：报根因也要有隔离实验

复核方判断「根因 = 碰撞没跳过固体」。我按单修了，但也做了隔离实验：
保留该修复、只换回旧出口 BC → Cd 立刻掉回 1.76（质量 +10.6%、出口流量只有入口 68%）；
换回对流出口 → Cd 回到 3.12。**⇒ 真正让物理错的是出口边界条件，固体碰撞 bug 虽是真的、却被反弹边界隔离在固体内部。**
（证据：两版**流体**质量逐位相同。详见 `result.md` 第三节）

> 教训：**"修好了"和"知道是哪一处修好的"是两件事**；下根因结论前先做单变量隔离实验。

## 🔴 第三条教训：统计窗口必须由判据自动裁，不能手挑（2026-10-19 复核方指出）

第三次被打回的原因：我把统计窗口取在了**瞬态段**（末尾 1 秒），那一段质量平稳、Cd 却还在往下掉，
于是报出的 St/Cd 是"半路取的样"。**现在的三道门禁（顺序不可跳）**：

1. **① 质量守恒**：稳态窗口内流体总质量相对漂移 < 0.1%（拦住"发散片段伪装成正常数"）；
2. **② 稳态判据**：把**最后 1/4 演化时长**自动切 4 个子窗，各算 Cd 均值，要求**相邻子窗相对变化 < 0.5%**
   （拦住"瞬态段当稳态"）；辅助 Cl 幅值跨子窗锁定在 ±3%。
   ⚠️ 判据**不看"Cd 是否恒定"**——圆柱绕流 Cd 自带约 2% 周期振荡，那是物理的一部分。
   **窗口由代码自动取，不许手动挑**；
3. **③ 才准报数**：前两道过了才做 St/Cd/Cl 对照。

任一不达标 → 如实写「未收敛，X%/窗」，**不许挑一段像样的报数**。
